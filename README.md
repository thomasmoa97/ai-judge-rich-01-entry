# Make the AI Judge Rich — Entry

[![make.fun](https://make.fun/badge/ai-judge-rich-01?label=make.fun)](https://make.fun/bounty/ai-judge-rich-01)

A program that writes one short plan to `/output/entry.txt`: the plan an AI agent would follow, starting with $100, a computer with internet access and 30 days, and no human doing the work, to end the 30 days with the most money.

## The plan

Win make.fun bounties in the thinnest fields. Rank every open bounty by entrants per paid place (lowest first), keep only escrowed ones with prizes of $100 or more and no entry fee, and submit one real, kit-checked Python program a day. At 5–10 entrants per paid place, 15–20 entries should land 1–2 wins ($250–800 by day 30), and the $100 stays mostly unspent because most bounties cost nothing to enter.

## Entry

`main.py` (Python 3.13, standard library only) writes the plan to `/output/entry.txt`. The plan is 882 UTF-8 characters, and two runs write byte-identical output.
